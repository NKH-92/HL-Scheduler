중요 주의사항

- 공개 일정 가져오기와 JSON 불러오기는 현재 편집본을 덮어씁니다.
- 자동 저장은 현재 브라우저/PC 기준입니다.
- 다른 PC에서 이어서 작업하려면 JSON 백업을 사용해야 합니다.
- 팀 공유는 공개 업로드 기능을 사용해야 합니다.
